# Flappy Bird

A Flappy Bird game you can play in your browser.

**Play here:** https://barnwalshlok-eng.github.io/flappybird/

## How to play
- Press **Space**, **click**, or **tap** to make the bird fly.
- Avoid the green pipes.
- Each pipe you pass gives you 1 point, and the game gets faster as you go.
